Delft implemented a cool online visitor permit reservation system. Which is great!

Unfortunately, they provided no ability to make a repeating reservation or save a preferred "favourite" to reprogram with a click. 

I discovered the awesome dvsportal library:

https://pypi.org/project/dvsportal/
https://github.com/ChessSpider/py-dvsportal

With relative ease, I can now with just a few clicks program the next 12 weeks of repeating reservations! (And maybe more, although there is some unclarity in the API, see https://github.com/ChessSpider/py-dvsportal/issues/2)
